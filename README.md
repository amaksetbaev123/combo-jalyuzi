## 🌟 Жойбардың тийкарғы өзгешеликлери:

1. **Бас бет (Hero Section):**
   - Сатыўшы күшли заголовок ҳәм офферлер.
   - Нөкис қаласы бойынша 100% бийпул өлшеў, жеткерип бериў ҳәм орнатыў акциясы.
   - 4 түрли кепиллик белгиси (Өз өндирисимиз, 24-48 саатта таярлаў, 1 жыл кепиллик, 0 сум орнатыў).

2. **Интерактив «Combo» (Күн & Түн) Симуляторы:**
   - Пайдаланыўшы слайдерди солға-оңға жылжытып, жалюзи полосаларының жарықты қалай өткеретуғынын (Күн / Жартылай / Түн режимин) жанлы түрде көре алады.

3. **Толық Каталог 2026 (Маталар & Модельлер):**
   - Интерактив категория фильтри: Барлығы, Combo, Rolletler, Dikiy, Plice, Blackout 100%.

   - «Көриў» түймеси: Толық мағлыўматлы модаль терезе (мата курамы, рең палитрасы, кепиллик).
   - Бир басыў менен буйыртпа бериў ҳәм үйиңизге 200+ мата үлгилери бар толық қағаз каталог пенен шеберди бийпул шақырыў блогы.

## 📂 Файллар дүзилиси:
- `index.html` — Негизги веб-сайт бети (Tailwind CSS, FontAwesome ҳәм Google Fonts интеграцияланған).
- `style.css` — Қосымша стильлер, анимациялар ҳәм рең өзгерислери.
- `script.js` — Интерактив симулятор, калькулятор ҳәм форманы басқарыў скриптлери.
